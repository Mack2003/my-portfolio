# Responsive Check

- Breakpoints: phone 0–639px, tablet 640–1023px, desktop 1024–1535px, large 1536px and up.
- Follow per-section rules from the Phase 4 brief when supplied; it is currently missing.
- No sideways scroll down to 360px. Text must not be smaller than 14px; touch targets at least 44px.
- Verify 390px, 820px and 1440px widths. Also check 360px for overflow and reduced-motion behavior.
- Inspect each affected component only; use `project/sections-map.md` before searching.
- Report viewport, browser/tool and any unchecked behavior. Never claim visual validation not performed.

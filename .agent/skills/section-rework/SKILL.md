# Section Rework

1. Read `project/sections-map.md`; inspect only the target component and its marked reference block.
2. State the design in three lines: goal, tokens/shapes/motion, responsive behavior. If direction is open, offer two options and ask.
3. Preserve verified content; consult `rules/03-content-truth.md`. Ask Malay for unknown facts.
4. Rebuild only the target section with project tokens and shared shapes; no generic default-AI layout.
5. Add motion only when it improves feedback and follows `motion-animation`.
6. Check phone/tablet/desktop at 390px, 820px and 1440px; ensure no horizontal scroll at 360px, 44px targets, focus, contrast and reduced motion.
7. Check performance, run build/lint, and update `project/sections-map.md` and `project/status.md`.

Do not read other sections or modify unrelated files. Follow the exact-copy phase first; rework only when Malay names the section.
